# 可靠的 macOS AI 输入辅助

> Status: active

## Statement

在保留 Rime / Squirrel 输入权威的前提下，让 AI 与 RAG 辅助候选真正进入 macOS 输入前台，并在删除、切换、选择和持续输入中保持可靠。

## Observable anchors

- 真实 Squirrel 前台可以显示、失效并选择与当前输入上下文一致的 AI / RAG 辅助候选。
- Rime / 万象继续负责拼音解析、原生候选、翻页和普通数字键，助手能力不替换其解码路径。
- 后续记忆、Control Center、Agent、Room 与项目工作台都能追溯到这个真实输入需求如何逐步扩展。
