# 可持续交付的个人 Agent 工作台

> State: unreached

## Statement

让输入、Agent、Room、记忆和工具成为一个可长期推进的个人工作台：用户能从项目愿景找到正确 Room，理解每项需求为何存在，继续交付，并用真实可观察证据确认结果符合自己的要求。

## Completion observations

- 所有必需 Room 都完成质量门与独立复核，并保留新鲜的可观察验收证据。
- 涉及人类可见体验的 Room 都完成用户亲自验收，不能以截图、Mock、健康检查或终端状态替代。
- Project 仍能从初始愿景追溯到每个 Room 的需求、交付结果和来源回执。
