# Project 是长期空间

> 状态：closed
> 类型：domain decision

## Question

用户切换 Project 时，是进入一个目录、打开一个 Dashboard，还是回到一个长期存在的工作空间？

## Resolution

Project 是长期存在的空间。每个 Project 保存自己的 Room 布局、摄像机位置、聚焦 Room、草稿和最近访问点。切回 Project 时恢复离开现场，不打开默认首页。

Project Map 只投影初始愿景、Room 需求与关系、交付阶段、验收、来源和空间位置。Room、Session、记忆、权限和终态仍由各自权威 owner 持有。

## Rejected alternatives

- 文件夹 + 聊天列表：仍然要求用户按系统对象寻找上下文。
- Dashboard 卡片：能报告状态，但不能形成长期空间记忆。
- 季度时间轴：把时间误当作主要检索线索，无法表达散装优化与并行方向。

## Basis

- 用户明确要求 Project 成为长期存在的可视化操作空间。
- 2026-07-30 安装态缺陷记录显示，前端复制运行时状态会造成版本偏差和虚假结论，因此地图必须保持投影边界。
