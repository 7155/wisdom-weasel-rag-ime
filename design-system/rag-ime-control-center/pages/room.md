# Room 工作台

继承 `../MASTER.md`，并覆盖以下规则：

- 使用与 Session 相同的列表宽度、状态面板宽度、边框和 Paper 阅读面。
- 顶部使用与 Session 相同的 48px 半透明悬浮结构栏，承载 Room 身份与 Posts / 执行 / Sessions 切换。
- 话题上下文条限制在 1160px 阅读宽度内，使用更轻的透明 Paper，只承担导航，不形成全宽第二顶栏。
- Posts 时间线从工作区顶部延伸到底部，并用 94px header space 保护首条 Post。
- 执行阶段信息与输入框组成一个透明浮动簇，不铺设全宽底色；输入框高度、内边距、工具栏、圆形发送键和阴影必须与 Session 一致。
- Room 消息、参与者消息和 Session 消息统一使用 15px / 1.66、同一进入动效与用户气泡色。
- 1360px 及以下的状态面板使用与 Session 相同的焦点受管抽屉；760px 及以下 Rooms 列表也锁定焦点并使背景不可交互。
- Rooms 列表在 761px 以上持续支持拖动、键盘调整、双击复位和本地宽度记忆。
- `@` 菜单复用全局菜单阴影、圆角、键盘导航和焦点规则。
