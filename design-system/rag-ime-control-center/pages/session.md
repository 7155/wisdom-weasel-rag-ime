# Session 工作台

继承 `../MASTER.md`，并覆盖以下规则：

- 三列结构：任务列表 / 对话 / 状态，默认 224px / 剩余空间 / 312px。
- 对话标题行 48px，并与品牌、任务列表和状态标题对齐；标题作为半透明悬浮层，时间线从工作区顶部一直延伸到底部。
- 时间线首部保留 56px 安全区，保证回到顶部时第一轮不被标题遮挡；滚动后内容可从标题下方自然经过。
- 正文使用 15px / 1.66，输入框与 Room 共用相同的 15px 字号、66px 最小输入高度和 1160px 最大宽度。
- 工具活动、计划、附件保持最大 620px；长正文使用主列可用宽度，不再额外压缩聊天。
- 状态面板默认收起；1360px 及以下作为焦点受管抽屉，Escape 关闭并把焦点还给触发按钮。
- 任务列表在 761px 以上持续支持拖动、键盘调整、双击复位和本地宽度记忆。
- 忙碌状态仍允许输入，明确区分“干预”和“接续”。
