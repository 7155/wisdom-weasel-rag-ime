# 渲染族覆盖矩阵（对话体验）

分类严格区分三种性质，避免把"预览能画出来"误当成"产品可达"：

- **产品可达**：真实事件/契约路径可以产生，已在真实页面渲染并检查。
- **仅预览夹具**：由 preview/mock 夹具驱动，用于视觉评审；不代表运行时一定会产生。
- **校验拒绝**：构造的形状被 block 校验拒绝，未进入渲染器——不得据此声称覆盖。

## 消息块渲染器

| 渲染器 | 性质 | 证据 |
|---|---|---|
| text / markdown 正文 | 产品可达 | 默认会话与长对话均渲染 |
| code | 产品可达 | 默认会话代码块 |
| diff | 仅预览夹具 | 渲染族样例；含 +/− 符号通道、行号、文件路径 |
| file | 产品可达 | 默认会话 room-runtime-handoff.md |
| citation / reference | 产品可达 | 默认会话本地计划引用 |
| checklist / table / status | 仅预览夹具 | 渲染族样例 |
| progress | 仅预览夹具 | 渲染族样例；此前渲染为无边无底的孤儿块，已并入 insert 家族 |
| artifact | 仅预览夹具 | 渲染族样例 |
| approval | 产品可达 | 会话内可决策（本轮修复回调链）；协作空间按设计只读并跳转 ReviewLink |
| image / sticker | 产品可达 | 默认会话 |
| audio | 产品可达（播放取决于后端） | 渲染族样例；`<audio>` 只接受受控 `/api/agent/...` 回执 |
| file（HTML 报告） | 产品可达 | 报告交付会话与协作空间 room_post；专用报告卡 + 沙箱预览 |
| file（普通受控文件） | 产品可达 | 同一会话内的 md / csv；csv 回执故意不可读，走错误与重试 |
| error（块级） | **校验拒绝** | 构造的 error 块在进入渲染器前被丢弃；产品实际以 turn 级失败面呈现 |
| unknown fallback | 仅预览夹具 | 曾为孤儿块，已并入 insert 家族 |

## 结果视觉层级

- 所有富结果共用“语义悬边、图标井、轻着色标题带、近白阅读正文”，不再是同一灰底上的
  机械矩形；语义色只负责识别与状态，不大面积淹没内容。
- Checklist 未完成为 Warning、完成为 Success；数据表与运行中为 Info；
  Diff、代码和任务计划为 Project；失败为 Danger；产物与受控文件按类型映射。
- 表格中的“已覆盖 / 需确认 / 失败 / 进行中”等状态拥有文字、色点和字重三重通道，
  但普通单元格保持中性，长表仍适合扫读。
- Diff 支持标准 unified patch，也支持 Agent 常见的“文件名在 block、正文只有 `@@` hunk”
  形态；后者只在本地补回展示路径后解析，不修改契约或文件内容。
- Diff 的单栏/并排切换被收进代码工具栏，使用图标加短标签和低对比选中面；
  不再出现白色大分段控件压过代码的情况。
- “回到最新”属于 Composer 的顶部状态行，并纳入实测 dock 高度；不会再浮在表格、
  Diff 或工具结果上方。

## 轮次与工具状态

| 状态 | 性质 | 证据 |
|---|---|---|
| running（工具在飞） | 仅预览夹具 | 状态与恢复会话：正在处理 + 工作指示 |
| failed + 重试 | 仅预览夹具 | 状态与恢复会话：本轮失败 + `.agent-turn__failure` + 「重试本轮」 |
| aborted（用户停止） | 仅预览夹具 | 状态与恢复会话：已停止；与失败视觉可区分 |
| completed | 产品可达 | 默认会话 |
| queued（工具级） | **契约不可达** | 事件流没有 queued 动词，`tool_started` 即已开始 |
| 模型切换（同串对话换模型） | 仅预览夹具 | 模型切换会话：两轮分别携带 `model`/`provider`/`usage` |

## 现代编辑纸张（视觉方向修正）

- 纸张从 hue 92 / chroma .008 改为 hue 250 / chroma .0022：整页仍读作奶油色是
  "羊皮纸"的失败模式。现在纸与环境同属冷色族，靠**明度**而非色相分离。
- 阴影基色由 sepia（`rgb(46 38 24)` 等 7 组）改为冷石墨：暖褐阴影会让任何
  中性纸重新读作陈旧纸张。
- 正文油墨改为石墨 L .205，而非近黑。
- **display 不再是衬线角色**。Songti 页标题把 任务 渲染成木刻感的历史标题；
  改为同一套无衬线的更重、更紧的切割。实测 12 条路由**产品外壳中不存在衬线**。
  `--font-editorial-serif` 保留但无任何规则引用，只作显式选择存在。
- 章节标题左侧 2px 强调刻度：稀疏页面的标题原本悬空无参照，这是"边缘与旁注"
  而非纹理的做法。

## 动效语言

一个动词：内容**落到栅格上**（`paper-settle`，4px 上移 + 淡入，180ms）。
两条消息族此前只是纯 opacity 淡入，没有方向感，结果就是"静态文档被重绘"。

- 明确拒绝：缩放（SaaS 弹跳感）、模糊、翻页与墨迹隐喻。
- **同一对象状态变化不重新入场**，只就地交叉淡入（`paper-restate`）：
  工具 running → done 若重放入场动画，会读成三个不同的工具依次出现。
- 入场只在 `data-turn-status='running'` 的回合内生效。虚拟列表回收行时，
  挂载动画会在向上滚动时重放整段历史的入场——这会让长会话更糟而不是更好。
- 减少动效下 `paper-settle` 时长为 0.001s（实测）。
- 120 条消息长对话上输入 19 字符耗时 124ms。

## HTML 报告交付

生成的报告是用户真正要的东西，因此不再与原始 CSV 共用同一个单行文件条：

- **报告卡**：仍属 insert 家族（620px、3px 悬边），以强调成员出现；
  强调仅来自强调色边与说明按钮，不另起一套卡片语言。
- **安全声明前置**：「不执行脚本、表单与外部请求」写在卡上，
  因为这是读者愿意打开生成 HTML 的前提。
- **沙箱**：`sandbox=""` + CSP + 元素/属性白名单。夹具里的报告**故意**带有
  `<script>`、`onload`、外链样式表、远程图片与 `javascript:` 链接。
  实测：`document.title` 未被脚本改写、脚本/表单/link 计数为 0、
  远程 `src` 被剥离、`javascript:` 链接被剥离而页内 `#锚点`保留、
  **零外部请求**、无 alert；同时正文、表格四行、作者样式全部保留。
- **被剥离的媒体**不再留下破图占位，改为虚线标记「已移除远程媒体：<alt>」。
- **对话里的原始 HTML** 永远不执行。`react-markdown` 原本会整段丢弃 HTML 节点，
  引用的markup 直接消失；现改为转成字面文本（`remarkLiteralHtml`），
  可读且仍然惰性。

## 本轮修正

- `--color-text-secondary` 在暗色下距 tertiary 仅 .015（亮色为 .075），
  三级文字在暗色里塌成一级。已对齐亮色步长（.84），对比度 9.71:1。
- 每轮模型此前与 Token 数同为 tertiary，同一串对话里换模型在视觉上不可见。
  模型改用 secondary，把"身份"与"计量"分开。
- 预览对话框此前用三行固定 grid，而截断提示是条件渲染的：提示不存在时
  正文落进 `auto` 行，塌成 HTML 预览的 520px `min-height`，780px 对话框里
  留下约 190px 死白。改为 flex 列后正文始终占满剩余空间。
- 输入区停靠条比文本行高，工具条一带点击无反应；现在点击非控件区域会把
  光标放回输入框。
- 时长格式化：原始毫秒在一秒以上就不再是信息，运行中工具曾显示
  `98530095 ms`。改为按最大诚实单位（ms / 秒 / 分 / 小时），亚秒仍用 ms。
- `queued` 与 `aborted` 不在状态词表中，落入通用分支显示为「已记录」：
  未开始的工具和被用户停止的工具都自称"已归档"。已补齐。
- `completeTurn` 只结算 `running` 块，`queued` 块在回合结束后永远显示排队中。
  已一并结算；中止回合结算为 completed 而非 failed（用户主动停止，不是故障）。
- 重试改为**确认请求**而非宣称结果：按钮变为「已请求重试」并禁用防重复提交，
  键控于 `turnId:status`，后端一移动回合即释放，失败提交不会永久卡死。
- `.ui-switch` 命中区经伪元素扩到 25px（视觉仍为 34×20）；
  会话搜索框与 `.agent-tool-destination` 补足 24px 目标尺寸。

## 已知取舍

- 活动状态枚举只有 `running / waiting / completed / failed`，没有 `aborted`。
  中止轮次的在飞工具被归为 `completed`（轮次头部已明确写「已停止」），
  因为标为 `failed` 会把"用户主动停止"误报成失败。若需要精确区分，
  需要后端语义新增活动级 `aborted`，不在前端伪造。
- 未做"本轮换了模型"的显式变更标记：需要在每条消息上跨消息订阅上一条的
  模型，流式期间成本不划算。改为提升模型本身的层级，使相邻两轮的差异可扫读。
- 预览夹具的 `previewNow` 是固定常量，因此"运行中"轮次的实时时长会显示为
  巨大数值。这是夹具时间基准问题，不是产品缺陷，未据此改动产品格式化。
