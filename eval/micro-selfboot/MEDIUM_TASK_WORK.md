# 中等任务：成功完成与持久接续

用户原文：“在来个中等大小任务大小。因为多agent，主要不是省token，而是任务成功和持久不便宜”。本轮把“持久”落实为跨阶段产物、真实 Pi Host 关闭重启、既有 Session 恢复或其他伙伴接手，完成追加需求且不丢已完成工作。多日运行与活跃写入时强杀不在这次小预算观测内。

任务为一个可恢复的 Lab 事件账本：Python/SQLite 存储、事件状态与成本汇总、CLI 导入导出，随后增加 usage 去重和调用身份校验需求。两个源码副本在付费调用前冻结；Host 验收器位于演员工作区之外，不投递标准答案。

| 阶段 | 单 Session | Room | 验收与依赖 |
| --- | --- | --- | --- |
| 存储 | 同一 Session 实现存储 | 存储伙伴实现 | 幂等、作用域、持久化、冲突；写交接说明 |
| 报告与 CLI | 原 Session 继续 | 报告伙伴接续文件 | 区分执行与质量、未知成本、CLI；依赖稳定存储 API |
| 关闭重启后追加需求 | 从原 transcript 恢复同一 Session | 新整合伙伴读取工作区与交接 | 新 usage 合同、保留旧库、实际交付文件、全部回归 |

同模型 Luna low、相同起始代码、相同阶段输入/验收与上限。伙伴责任和 Session 身份是被测 workflow 差异；Room 交接上下文不等于单 Session 的完整私有历史，因此只报告这套实际配置的比较。两侧各三个工作阶段，允许原生 Pi Tool loop 自行实现、测试与修复，不把单 Session 限制为一次回答。Room 串行执行以控制机器负载，不声称测了并行加速。

主指标：一个完整任务通过或失败；分层列出实现合同与实际交付检查。次指标：恢复后完成、已完成结果保留、重复导入/重复计费、验收回归。成本、完整 turn tokens、耗时单列，不预设多 Agent 更便宜或更成功。

预算为主 Session 的本轮实现选择：每臂三个阶段、18 次实际模型调用、100k 观察 tokens、每阶段 300 秒、单次输出 4096。观察到上限时通过 Pi Stop 收口；在途调用可能越界，未知费用不记零。两臂均允许同样资源，只有一个固定配置，不重跑挑选最好结果。

主 Session 负责夹具、Host 验收、运行和报告；被测代码仅由被测 Pi Session 产生，主 Session 不代修候选答案。所有模型产物与数据库在仓库外私有评测目录，源码工作区保持分离。回滚为停止该隔离 service 并保留回执；不修改生产库或已安装 Runtime，不提交或发布。

## 环境诊断与同规模新题

进一步定位到 WorkspaceHarness 的敏感文件策略：`.sqlite/.db` 文件在 actor 工作区与命令临时目录均禁止访问。Host 存储检查 6/6 在外部验收环境完成，不能证明 actor 的文件数据库测试可执行。增加 tokens 无法解决这一环境差异，因此搁置提高预算的选项。

2026-09-06 改用独立新题 `durable-lab-ledger-jsonl-v1`：Python 标准文件操作实现 UTF-8 JSON Lines 事件账本，原子替换、幂等、冲突、排序、CLI、追加 callId 需求及真实 Pi Host 重启接续全部保留，仍为 20 条实现检查与 4 条交付检查。它不是 SQLite 文件改名，也不修改或绕开敏感文件策略；实际交付额外读回每行 JSON，验证存储格式。旧 SQLite 工作区与回执保持原样，不改判原题成功。

新题双方从同一个空实现 seed 开始，运行前冻结新身份与 hash；相同 Luna low、每臂 18 次调用 / 100k 观察 tokens / 三阶段。先经真实 workspace Tool 做原子 JSONL 写入、fsync、替换和读回预检，才准入付费调用。原子文件持久化属于新的实现责任，未缩减完整交付与接续范围。OS Lab 将同时呈现旧阻塞和新题结果；图示把完整任务、实现检查、重复观察与代价分开。
