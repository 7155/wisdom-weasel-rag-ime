---
description: 检查当前项目并显式创建或补全根级 AGENTS.md
---
初始化当前 Session 绑定的项目工作区，让后续 Agent 能从根级 `AGENTS.md` 获得准确、精简、可执行的项目上下文。

执行要求：

1. 只以当前 Session 的第一个已绑定工作区根目录为项目范围。若没有可写工作区，停止写入并明确告诉用户先绑定项目目录。
2. 写入前先检查 `git status`，再阅读已有根级 `AGENTS.md`、`README`、包清单、主要源码入口、测试入口和安装脚本。忽略依赖、构建产物、缓存、历史副本和大规模生成目录。
3. 如果根级 `AGENTS.md` 不存在，则创建它；如果已存在，保留其中仍有效的项目约束，只补充经过源码或脚本验证的缺口。不要覆盖、清空或用通用模板重写现有内容。
4. `AGENTS.md` 只记录后续开发反复需要的稳定事实：
   - 项目目标、当前主要交付物和明确非目标；
   - 权威源码路径及每个关键模块的唯一职责；
   - 已验证的开发、测试、构建和安装命令；
   - 数据、安全、权限、运行时、Git 和发布边界；
   - 脏工作树中的保留规则，以及完成任务时必须报告的验证边界。
5. 内容保持短而具体，优先链接仓库内已有文档，不复制长篇设计、历史对话、临时进度、模型偏好或密钥配置。
6. 不自动创建其他项目文档，不修改业务代码，不提交 Git。若现有 `AGENTS.md` 已覆盖上述稳定事实，说明检查结果并保持文件不变。

完成后只汇报：检查过的权威入口、`AGENTS.md` 是否创建或补全、具体新增的稳定规则、尚无法从仓库验证的项目事实。
