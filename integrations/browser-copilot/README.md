# 澄 Browser Co-pilot

这是控制中心的浏览器感知与执行端，不是独立产品。

## 本地加载

1. 打开 Chrome 的 `chrome://extensions/`。
2. 启用“开发者模式”。
3. 选择“加载已解压的扩展程序”，指向本目录下的 `extension/`。
4. 启动澄 Sidecar 后，点击扩展图标。插件会从本机 `8766` 控制服务取得配对凭据。

插件持续同步结构化页面快照，完整正文、截图和 Base64 数据不会自动注入 Agent 上下文。Agent 只能通过 `browser` 按需读取或提交经过批准的操作。

扩展默认自动允许 Agent 发起的跨站导航，并在本机权限记录中留下 `allow_once` 审计记录；导航会在同一条命令中继续，不需要回到控制中心批准或重新发送消息。若希望逐次确认，可在扩展侧栏的连接设置中关闭“自动允许站点跳转”。
