### UR-249 — 白色工作界面保留星空身份并重新建立界面品质

- **状态 / 优先级：** `current / P0`
- **直接来源：** “本项目其实目前ui设计是不太好的，之前只是做完了”；“能做成星空主题吗，我们项目本身也是星空”。
- **需求：** 既有界面只作为功能参考，重新优化视觉和交互。沿用项目星空身份，统一桌面、Agent 和 Room 的背景、层次、行星、字体与动效。
- **后续直接修正：** “深色不好，还是白色吧，app少有见到深色设计”；“你要有审美把控”。此修正覆盖本轮曾采用的深色工作界面；星空身份不等于深色底。
- **当前实施解释：** 白色主界面、轻浅灰层次与节制蓝色操作点；用行星、轨道、关系和真实消息流表达星空身份。伙伴为行星，真实 Tool Agent 为各自行星的卫星。长正文和编辑区保持安静，动画表达真实状态变化。重新检查留白、文字密度、主次与窄窗交互，不仅替换颜色。
- **验收：** 真实 Session/Room 在桌面与窄窗中可读、可操作；不得仅交付视觉稿或让背景装饰妨碍结果阅读。

### UR-250 — 重做协作消息流转与各行星卫星状态数量

- **状态 / 优先级：** `current / P0`
- **直接来源：** “协作的消息流转展示需要重做，能看到互相消息怎么流转和各自行星的卫星状态数量”。
- **需求：** 可看到伙伴之间的发送者、接收者、消息流向以及对应的消息内容和回复；每颗行星显示其实际卫星数量及运行状态。
- **实施解释：** 复用现有 Room 公共事件、直接通信和 Session Tool Agent 数据；保留双向通信，展示排队、送达、回复或失败等已知事实。卫星归属对应伙伴 Session，按稳定节点身份去重；未加载或读取失败显示未知，只有成功返回空列表才显示零。跨轮保留的 Session 数据须标明范围。
- **验收：** 从真实 Room 打开协作态势可追踪一条实际消息，并展开查看相关内容；各行星的卫星状态计数能追溯到真实子 Agent。历史消息不靠持续播放动画假装仍在运行。
