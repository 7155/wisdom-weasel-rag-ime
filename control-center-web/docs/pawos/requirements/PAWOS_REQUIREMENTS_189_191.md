### UR-189 — Agent 文件 Rich Block 只保留一个可操作容器

- **状态 / 优先级：** `current / P0 frontend usability`
- **真实需求：** Agent 时间线里的同一份文件、Markdown 或 diff 不能被
  “文件版本”“当前文件”“最近修改”和预览器多层卡片重复包裹。一个结果只显示
  一个文件块：顶栏承载文件名、类型、大小、收起、复制和打开；正文直接渲染
  Markdown 或 diff，并保留滚动与跳转能力。
- **验收边界：** 不能用隐藏正文或删除 diff/Markdown 功能来换取视觉单层；
  同一文件的当前内容与修改视图需要在同一个块内切换或按需展开。
- **原话依据：** “ui嵌套了，这个框一个就好”。来源：当前任务，2026-08-28。

### UR-190 — 项目文件夹采用 Agent × 文件夹图标并打开单一完整窗口

- **状态 / 优先级：** `current / P0 desktop usability`
- **真实需求：** 桌面的项目/对话归档必须保持真实可拖动图标，但项目图标要
  结合文件夹与 Agent/对话语义重新设计，不能使用粗糙的通用文件夹、粗黑线框、
  外挂的一圈箭头/设置/Agent 徽标或大块红绿状态底色。项目层不能压在首页宣传
  文案上；工作桌面使用干净壁纸，文件夹采用较小、柔和、有实体感的图标，PAW/
  Agent 语义作为低调内嵌标识，只保留一个小状态点。点击项目文件夹后打开一个
  漂亮、完整、可用的单一项目窗口；窗口内
  可按今天、本周、更早等时间分组浏览对话文件，内容可滚动，名称可读，点击进入
  对应 Session 或 Room。
- **验收边界：** 不能把每个时间分组分别画成相互覆盖的浮动面板；文字不能穿透，
  卡片不能重叠，状态只能作为辅助徽标而不能压过文件/Agent 身份。
- **原话依据：** “哈哈哈哈，给我气笑了”；“文件夹也是一个漂亮的界面呀，
  现在这个用不了，图标也丑，结合agent和文件夹图标画”；“而且这个太丑了”。
  来源：当前任务，2026-08-28。

### UR-191 — Dock 常驻且所有 App 窗口可最大化与恢复

- **状态 / 优先级：** `current / P0 desktop windowing`
- **真实需求：** PAWOS Dock 采用 macOS 式视觉与窗口状态点，但按最新纠正平时
  常驻显示，不自动隐藏。所有普通 App 都是可拖动、可调整大小的桌面窗口；
  绿色按钮或双击标题栏可把窗口最大化到整个可用桌面，再次操作恢复先前尺寸与
  位置。
- **边界：** 普通 App 最大化不等于浏览器 Fullscreen API，也不改变 Room 协同
  模式的中间主窗与行星窗口语义；Dock 可作为覆盖层常驻底部，最大化窗口仍应
  充分使用桌面空间。
- **修正关系：** 最新“docker平时不要隐藏”明确 supersede 同日较早的“平时
  隐藏”；常驻 Dock 是当前控制语义。
- **原话依据：** “docker栏和mac一样，平时隐藏，所有app是可以全屏的，窗口能
  拉大到全屏的”；更正：“docker平时不要隐藏”。来源：当前任务，2026-08-28。
