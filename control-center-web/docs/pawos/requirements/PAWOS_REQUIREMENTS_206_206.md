### UR-206 — Room 行星按“未分配、协作执行、最终结果”分面展示

- **状态 / 优先级：** `current / P0 collaboration clarity`
- **真实需求：** 行星任务表只承载已经分配并进入协作执行的行星。只有一颗行星
  且尚未分配时，不显示表格，改为保留 Grill Me、直接对话与进入该 Session 的
  独立起始面。行星完成并提交结果后，也必须移出任务表，作为包含最终结果、证据
  与原 Session 入口的独立结果行星展示；同轮仍在执行的其他行星继续留在表格中。
- **原话依据：** “那个，行星是表格对吧。两种情况不能表格，就是单行星没分配的时候，这时候有grill me这些。第二，结束后提交结果，那个结果行星不能表格，得单独。”来源：当前任务，2026-08-30。
