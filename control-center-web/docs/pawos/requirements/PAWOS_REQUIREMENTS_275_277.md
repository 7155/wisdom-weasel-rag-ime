### UR-277 — 自转、轨道与真实感运动模拟

- **状态：** `current`。
- **直接原话：** “还有旋转，轨道，等等等等真实模拟”。
- **来源：** `msg_01a073df-3845-7d83-986d-46488cf58bd3`，`2026-09-05T23:20:03.909Z`。
- **修正关系：** 用户显式要求物理运动；覆盖早先 Agent 对“空闲行星必须完全不动”的推断。Runtime 执行状态仍由原服务投影，运动不等于 busy。
- **实施解释：** 固定自转轴、独立自转、倾斜和非圆轨道、引力场中的速度变化，旋臂形态与单颗天体差速运动分开；提供暂停和时间倍率。当前选择 Plummer 星核加有核对数晕的测试粒子近似，并采用稳定旋臂图案；这是 Agent 的实现选择，不是用户指定公式。
- **验收：** 轨道积分的能量/角动量漂移有检查；实际暂停冻结、恢复连续、倍率有效；长时间运行不卷成密集同心环。说明时间和尺度被压缩，不声称完成全自引力 N 体、星历或科学标定。
