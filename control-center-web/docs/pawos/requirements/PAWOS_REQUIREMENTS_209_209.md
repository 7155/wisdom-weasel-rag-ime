### UR-209 — 用户可以从桌面移除图标并可恢复放回

- **状态 / 优先级：** `current / P1 desktop control`
- **真实需求：** 用户可以从桌面移除图标。移除/隐藏图标只改变桌面可见性与布局，
  不等于卸载 App、归档项目、删除 Session/Room/项目文件或删除任何用户数据；必须
  保留可发现、可恢复或重新放回桌面的入口。
- **用户可见验收含义：** 用户移除一个桌面图标后，该图标不再占用桌面；其 App 或
  对象仍可经全部 App、相关目录、已固定 Dock 或明确的恢复入口重新放回。移除项目
  文件夹图标时，项目与其中对话状态不得被修改。
- **必须保留：** 桌面图标、App 安装状态、项目归档、Session/Room 归档和数据删除
  的不同权限、确认和 Runtime 语义。
- **不得做：** 不得把“移除图标”映射为卸载、归档或删除；不得让不可恢复的隐藏状态
  成为唯一结果；不得从这一条推导任何 App 的安装/启用状态。
- **依赖 / 顺序：** 先确认桌面持久化布局和恢复入口的真实所有者；再验证移除、
  重启恢复、重新放回和对象数据不变。状态账本当前为 `unassessed`，任何源码或截图
  均不单独构成完成证明。
- **完成态证据层级：** 后续至少需要 E1 桌面布局/恢复所有者源码，E2 移除与恢复且
  不影响 App/对象数据的回归，E3 生产构建，E4 安装，E5 已安装状态读回，以及 E6
  前台移除并恢复同一图标的用户可见验收。
- **原话依据（无损转录）：**

  > 桌面图标可以移除
