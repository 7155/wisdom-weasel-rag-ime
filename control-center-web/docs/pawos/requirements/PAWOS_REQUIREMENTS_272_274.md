`current` 表示控制语义，实施和验收程度见[状态索引](../PAWOS_REQUIREMENT_STATUS.md)。这些直接修正保留此前 Browser、暗色、后台 Agent 和 OS 性能要求。

### UR-272 — 打开项目文件夹直接展开立体星系，行星旋出

- **状态：** `current`。
- **直接原话：** “文件夹点开能否选择可视化为全屏星系来选择，星系能看到各个行星进度和星球状态，还有这个项目的docs。点开就弹出星系。大气，不要这种粗糙的二维贴图，直接酷炫的星系，点开就星球旋出”。
- **来源：** 继续任务 `01a071a1-a095-7e73-a2d5-e97cfefaa09f`，`msg_01a07220-c101-7f30-bec7-cb59f73d8f1a`，`2026-09-05T15:12:24.321Z`。
- **修正关系：** 覆盖 UR-271 中“先打开列表，再选择全屏星系”的默认入口和二维行星排布。保留实际状态、进度和项目 docs；文字列表作为次级入口。
- **实施解释：** 桌面沿用双击/Enter/空格打开文件夹；打开动作直接进入全视口 3D 星系。一次旋出和后来 [UR-277](PAWOS_REQUIREMENTS_275_277.md) 显式要求的轨道模拟都不能冒充 Runtime 执行状态。
- **验收：** 实际文件夹直接打开、立体视角和选择、进度/docs、返回焦点、减少动效和资源释放；静态截图不能证明旋出动画或 Runtime 在执行。

### UR-273 — 重做项目星系渲染器

- **状态：** `current`。
- **直接原话：** “项目已有的 3D 渲染器，这个很不好看，你要不然就重做”。
- **来源：** 同一继续任务，`msg_01a0722d-3db4-7581-b5f5-3c4efcce6447`，`2026-09-05T15:26:02.676Z`。
- **控制关系：** 明确拒绝本轮提出的复用旧 `StarfieldStage` 视觉实现。旧 Session/Room 星场及其已有消费者不由此自动删除；新项目星系使用独立渲染器。
- **实施解释：** 新 Three.js 场景、球体明暗面、大气边缘、行星环和三维旋臂；不以圆形图片裁剪代替球体。早期程序化材质随后被 [UR-275](PAWOS_REQUIREMENTS_275_277.md) 拒绝，当前材质验收以该修正为准。Three.js 基础库、真实数据边界及文件读取能力可以继续使用。
- **验收：** 需实际浏览器渲染、交互和窄屏检查；不能只换 CSS 或名称后声称已经重做。

### UR-274 — 修正思考指示器的星核偏心

- **状态：** `current`。
- **直接原话：** “ui是不对的，星球不再中心”。
- **来源：** 同一继续任务，`msg_01a07230-f9b3-7841-9cab-91429cfac230`，`2026-09-05T15:30:07.411Z`。
- **附件定位：** `codex-clipboard-23df07b6-12d8-4086-97e5-bed115efe4e9.png` 展示“思考中”条的星核位于轨道左上角。附件用于定位 UI 问题，不证明真实思考时间或 Runtime 状态。
- **实施解释：** 修复状态条对子级 span 的排版覆盖，保证星核和旋臂共用中心。该修正针对小型执行指示器，不把项目星系内所有行星挪到一个中心点。
- **验收：** 在实际思考条布局中核对星核和轨道几何中心；保持思考、工具、等待、结束的原状态含义。
