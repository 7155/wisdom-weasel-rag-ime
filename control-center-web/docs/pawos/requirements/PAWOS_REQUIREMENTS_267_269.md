### UR-267 — 壁纸展示后台运行的多个 Agent 星球

- **状态：** `current`。
- **直接原话：** “星空重新做，然后多个agent后台运行的时候，我们壁纸就可以是星空展示多个星球这些”。来源 `msg_01a07186-0b8e-7e93-9457-a6ef52b46ac7`，`2026-09-05T12:23:25.327Z`，原任务。
- **纠正原话：** “点击星球打开对应窗口这个倒无所谓”。来源 `msg_01a07188-b346-73f3-8174-273248c705a7`，`2026-09-05T12:26:19.334Z`，原任务。
- **控制关系：** 强化 UR-265；一个固定装饰大行星不满足后台多 Agent 可视化。点击开窗不是本次壁纸重点，不新增强制点击验收；UR-262 的 Room 多伙伴独立窗口要求仍有效。
- **实施解释：** 复用桌面的真实 Session 目录；每个可确认运行的 Session 有自己的星球身份。Room 成员身份不能单独证明运行，不凭名字、窗口数量或共处 Room 生成协作连线。暂停动画与 Runtime 停止是不同状态。
- **验收：** 多 Session 同时显示、真实终态移除运行表现、旧数据不能复活运行、实际界面和减少动效行为分别验证。

- **状态：** `current`。
- **直接原话：** “浏览器不对，浏览器应该是完整浏览器。浏览器应该是完整浏览器，有记录有设置这些”。来源 `msg_01a071a5-70a2-7951-a144-5ed087c5b07c`，`2026-09-05T12:57:42.818Z`，继续任务。
- **实施解释：** 保留标签、地址、导航等浏览功能，使历史、设置可发现且实际可用；补齐书签、真实下载记录及操作。书签和下载是对“完整浏览器”的 Agent 实施分解，不伪造成用户逐项指定。
