### UR-196 — react-ui-os 只作为 MIT 参考源，实质复制必须保留许可声明

- **状态 / 优先级：** `current / P0 source governance`
- **真实需求：** 可以调查项目 ZIP 中的 `react-ui-os` 作为 PAWOS 交互、体验和
  性能优化参考；若复制其实质性代码，交付物必须保留对应 MIT `LICENSE`
  声明。仅吸收行为原则或自行重写时，也不得伪称该参考项目是 PAWOS 的运行时
  依赖。
- **原话依据：** “参考源码为 MIT；若复制实质性代码，需要保留其
  /tmp/paw-react-ui-os-audit.cl5Dsq/react-ui-os-main/LICENSE:1 声明。”来源：当前任务，2026-08-30。

  $impeccable polish 完成前台视觉验收。”；“完成”。来源：当前任务，2026-08-30。

### UR-198 — Dock 在普通桌面显示，活动窗口最大化时隐藏并在还原后返回

- **状态 / 优先级：** `current / P0 desktop windowing`
- **真实需求：** Dock 的显隐必须与用户指定的 macOS 交互一致：普通桌面和普通
  窗口状态显示 Dock；当前活动 App 最大化时隐藏；窗口还原后 Dock 立即返回。
- **修正关系：** 本条是 2026-08-30 的最新直接纠正，supersede `UR-191` 中可被
  解释为“最大化仍常驻 Dock”的部分；`UR-191` 的窗口最大化/还原合同其余部分保留。
- **原话依据：** “doker是应该和macos交互一致，最大化的时候隐藏”。来源：当前任务，2026-08-30。

### UR-199 — 项目区保持桌面文件系统形态并优化直接操作

- **状态 / 优先级：** `current / P0 desktop files`
- **真实需求：** 项目、Session 与 Room 继续以桌面文件夹/文件图标存在于一个可
  拖动、可选择、可打开的坐标平面；优化必须围绕这种桌面文件交互，不得退回
  列表、仪表盘或覆盖桌面的管理卡片。
- **原话依据：** “目前项目是桌面文件的形式，这个显示和交互需要操作和优化”。来源：当前任务，2026-08-30。

### UR-200 — 运行中的桌面文件和项目文件夹具有克制且可访问的运行特效

- **状态 / 优先级：** `current / P0 state visibility`
- **真实需求：** 真实运行态的 Session/Room 文件及包含运行项的项目文件夹要有
  一致的运行视觉反馈；动效不能移动命中区或造成布局抖动，并须在降低动态、
  页面隐藏和高频窗口交互时静止或暂停。
- **原话依据：** “比如运行中的，就加运行中特效”。来源：当前任务，2026-08-30。

### UR-201 — 菜单栏显示真实后台对话与自动任务并可点回原工作

- **状态 / 优先级：** `current / P0 background activity`
- **真实需求：** 顶部状态区显示当前背后正在运行的真实对话、Room 和自动任务，
  包括自动记忆整理与普通对话 Agent；入口展开后显示实际标题/状态，点击回到
  同一个 canonical Session/Room，不新建或重跑任务。
- **原话依据：** “这一块就可以显示，背后有哪些对话运行，比如自动记忆整理，对话agent”。来源：当前任务，2026-08-30；随附菜单栏截图只作位置参考。

### UR-202 — System Settings 与 System Monitor 同时作为桌面 App 图标

- **状态 / 优先级：** `current / P0 desktop files`

  可选择、可拖动、可双击打开的桌面 App 图标存在，并复用普通 App 的窗口和
  运行态合同。
- **原话依据：** “设置和moniter也放桌面”。来源：当前任务，2026-08-30。

### UR-203 — 通知中心从桌面右侧非模态滑出

- **原话依据：** “这个notif也是侧边弹出”。来源：当前任务，2026-08-30；随附通知截图只作交互与位置参考。

### UR-205 — 桌面图标自动整齐化并重做项目/对话图标体系

- **状态 / 优先级：** `current / P0 desktop files`
- **真实需求：** 新桌面与旧散乱坐标要能落入统一网格，Settings/Monitor、项目
  文件夹和对话文件不得互相覆盖；提供再次整理图标的直接操作。项目文件夹、
  Session 与 Room 图标须使用统一尺寸/轮廓、可辨类型标识、固定两行名称和克制
  状态点，长名称不能撑乱相邻网格。
- **原话依据：** “整齐化，图标重做”。来源：当前任务，2026-08-30；随附桌面截图只作问题范围和视觉参考。
