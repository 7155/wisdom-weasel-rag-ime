# PAWOS 用户需求账本 · UR-278–UR-283

原话来自继续任务 `01a071a1-a095-7e73-a2d5-e97cfefaa09f`。`current` 表示当前控制语义，不表示实现完成。旧的完整 Browser、Astra 子 Agent、真实进度、docs 和 OS 性能要求继续有效。

### UR-278 — 行星和卫星窗口显示自己的模型

- **状态：** `current`。
- **直接原话：** “行星卫星窗口应该告知模型，例如gpt5.6sol之类的”。
- **来源：** `msg_01a07417-0fce-7660-9bde-9bebbdf3a7e6`，`2026-09-06T00:21:03.569Z`；附件 `codex-clipboard-f413e8f3-5bcb-4133-9fcf-fcc91b67d12a.png`。
- **解释与验收：** 窗口标题展示该行星/卫星实际绑定 Session 的模型；不得借用父 Session 或全局默认。未绑定或未读取到时明确未知。读取失败、模型切换、关闭窗口不产生错误归属或后台轮询。

### UR-279 — Session 同步自动恢复，减少反复手动同步

- **状态：** `current`。
- **直接原话：** “这个同步很烦人。我们插件和app装卸需要优化或者重做，就是agent自己，我们自己就能正在os内完成安装卸载或者制作。还有更加精细的插件管理，不同场景加载不同的”。
- **来源：** `msg_01a07417-9be6-7d73-9b9e-9174fb8754b0`，`2026-09-06T00:21:39.432Z`；附件 `codex-clipboard-4ac85118-4af8-4bdd-b341-ce3974f7649f.png`。同一原话也映射 UR-280、UR-281。
- **解释与验收：** 短暂网络断开进入自动恢复，不把可恢复状态永久留下为 Session 操作失败。保留已有聊天和草稿；真正操作失败、工作目录失效仍准确显示。自动恢复不能重发用户消息或不确定的副作用。
- **证据边界：** 截图中的旧构建同步报错是报告现象，不足以证明所有 Runtime 故障有相同根因。

### UR-280 — 人和 Agent 都能在 OS 中制作及装卸 App/插件

- **状态：** `current`；来源及完整原话见 UR-279。
- **解释与验收：** App Center 提供制作入口、来源检查、安装/启停/卸载和版本回执。人能编写可复用能力；Agent 使用正常 Pi Session 制作 App/Package。已有明确授权的同一安装通过当前 Session 权限完成，不重复转交产品确认；未授权或超出用途的变化仍需用户决定。
- **所有权：** Pi 原生 Package 解析和 Session 加载保持唯一。创建草稿、源码可用、已安装、已启用、当前 Session 已加载分别取对应真实回执。用户截图里的 Agent 建议只作参考，不自动扩成新增市场、签名、评价等用户需求。
- **当前范围：** 人工制作支持 Skill/Prompt；完整 App 制作复用既有 pawos-app-builder。当前源码没有声称已经真实制作或安装某个新 App。

### UR-281 — 不同场景加载不同能力，并保留已有对话快照

- **状态：** `current`；来源及完整原话见 UR-279；延续 UR-240。
- **解释与验收：** 在 App Center 管理普通对话、Room、Trace、Agent Lab 各自的 Skill 加载集合；场景专属能力保持归属。配置保存不因其他对话运行而要求整个 Pi Runtime 重启。新对话用新选择，已有对话保留实际资源快照。
- **边界：** Skill 的场景 allowlist 不等价于每个可执行 Extension、Prompt、Theme 都有动态卸载器；不把已选择的配置写成当前已加载的事实。
