# Code Of Conduct

Personal Agent Workbench is a technical, learning-oriented open-source project.
Participation should make the project safer, clearer, and easier to verify.

## Expected

- Be respectful, specific, and patient.
- Critique code, evidence, and design decisions rather than people.
- Distinguish verified behavior from assumptions.
- Protect private data and disclose security issues privately.
- Accept that maintainers may reject changes that weaken privacy, provenance,
  Rime compatibility, or lifecycle guarantees.
- Give credit for prior work and third-party sources.

## Not Accepted

- Harassment, discrimination, threats, or personal attacks.
- Publishing another person's private information or credentials.
- Deliberately misleading test, benchmark, provenance, or release claims.
- Repeated disruption after a maintainer has set a clear technical boundary.

Maintainers may edit, hide, or remove contributions and restrict participation
when needed to protect the project or its community. Report conduct concerns
through the repository owner's GitHub profile, or use a private Security
Advisory when sensitive information is involved.
