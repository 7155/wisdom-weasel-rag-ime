# PAWOS Showcase Assets

[Current feature gallery](current/README.md) contains 17 screenshots captured
from the 2026-09-08 source preview, with per-image routes and provenance.

## Earlier three-scene capture

These images are generated by `scripts/capture_pawos_showcase.sh` at
1440×900 from the public deterministic preview transport. They contain no
private Session, credentials, local database content, or personal input.

- `pawos-agent-trace.webp` — one Session's context-assembly evidence view.
- `pawos-room-focus-satellite.webp` — the public Room beside its detachable
  Sol collaboration overview.
- `pawos-room-starfield.webp` — the same Room projected as a shared starfield.

`showcase-manifest.json` records the base commit, working-tree fingerprint,
asset hashes, capture mode, and evidence boundary. The generated WebM stays in
the ignored `control-center-web/output/showcase/` directory so repository
clones do not carry a large binary by default.

The command reproduces the same named scenes and checkpoints with a fixed
browser clock and reduced starfield motion. Manifest hashes identify one
capture run; they are not cross-machine golden-image assertions because
Chromium and GPU rasterization can differ by a few pixels.

These are preview-fixture product scenes. They are not evidence of install,
live Runtime health, macOS foreground behavior, signing, notarization, or
release readiness.
